## 😤 مشکل

همه‌ی ایجنت‌های کدنویس — **Claude Code، کدکس OpenAI، Antigravity گوگل، Cursor، GitHub Copilot، Gemini CLI** — توکن رو در سه جا می‌سوزونن:

1. **کشف مجدد:** هر جلسه، ایجنت دوباره ریپو رو کاوش می‌کنه تا قراردادهایی رو بفهمه که دیروز فهمیده بود.
2. **کانتکست همیشه‌بارِ حجیم:** فایل‌های قاعده‌ی بزرگ (`AGENTS.md`، `CLAUDE.md`) هر نوبت دوباره ارسال می‌شن.
3. **آزمون‌وخطا:** تسک مبهم → کاوش → مسیر اشتباه → دورهای اصلاح. هر دور، کل گفتگو رو دوباره می‌فرسته.

نتیجه: پر شدن پنجره‌ی کانتکست، کندی، و هزینه‌ی توکنی که مدام رشد می‌کنه.

## ✅ راه‌حل

Agent Skills استاندارد باز ([agentskills.io](https://agentskills.io)) هست که بیش از ۴۰ کلاینت — از جمله Claude Code و Codex و Copilot و Cursor و Antigravity — پشتیبانی می‌کنن. هر skill یک پوشه با `SKILL.md` هست و ایجنت‌ها اون رو **تدریجی** بارگذاری می‌کنن:

| مکانیزم | چه اتفاقی می‌افته | اثر روی توکن |
|---|---|---|
| **کشف تدریجی** | فقط «نام + توضیح» هر skill (~۵۰-۱۰۰ توکن) در کانتکست می‌مونه؛ متن کامل فقط وقتی تسک مچ بشه لود می‌شه | جایگزین فایل‌های قاعده‌ی حجیمِ همیشه‌بار |
| **اسکریپت به‌جای کانتکست** | کار قطعی (سندسازی، آنالیز، اعتبارسنجی) با کد اجرا می‌شه نه با استدلال LLM | اون کار **صفر** توکن مصرف می‌کنه |
| **رویه‌های تأییدشده** | ورک‌فلوهای گلچین‌شده کاوش و مسیر اشتباه و دورهای اصلاح رو حذف می‌کنن | نوبت کمتر، نتیجه **بهتر** |
| **طراحی سازگار با کش** | پیشوندهای پایدار و جلسات لاغر → hit بیشتر کش پرامپت | توکن‌های کش‌شده تا ~۹۰٪ تخفیف می‌گیرن |

## 🚀 شروع سریع

```bash
git clone https://github.com/tmolavi/lean-agent-skills.git
cd your-project
../lean-agent-skills/install.sh          # نصب پروژه‌ای (پیشنهادی)
../lean-agent-skills/install.sh --global # یا سراسری برای همه‌ی پروژه‌ها
../lean-agent-skills/install.sh --dry-run # پیش‌نمایش بدون تغییر
```

نصب‌کننده همچنین یک `AGENTS.md` بیست‌خطی با قوانین صرفه‌جویی می‌نویسه (بدون `--force` هرگز روی فایل شما نمی‌نویسه) و `uninstall.sh` همه‌چیز رو دقیقاً برمی‌گردونه.

## 📦 کاتالوگ گلچین‌شده (۴۵+ skill)

- **anthropics/skills (رسمی):** `skill-creator` + skillهای اسناد (docx/pdf/pptx/xlsx) که کار رو به اسکریپت می‌سپرون
- **openai/skills (رسمی Codex):** سی‌و‌خورده‌ای skill curated مثل `gh-fix-ci`، `security-best-practices`، `playwright`، دیپلوی Vercel/Netlify/Cloudflare، Notion، Linear، Figma
- **andrej-karpathy-skills:** گایدلاین «تغییر جراحی، سادگی، معیار موفقیت قابل‌سنجش» — نگهبان کیفیت
- **skill-optimizer:** از تاریخچه‌ی جلساتِ خودت skill استخراج می‌کنه و skillها رو لاغر نگه می‌داره

فهرست ماشین‌خوان: [manifest.yaml](manifest.yaml) · حذف با `uninstall.sh`

## ❓ سؤالات متداول

**واقعاً هزینه‌ی توکن کم می‌شه؟** مکانیزم‌ها ساختاری‌ان: کانتکست همیشه‌بارِ لاغرتر، دستورالعمل‌های لود-بر اساس-نیاز، کار قطعی با اسکریپت، نوبت‌های کمتر، hit rate بالاتر کش. مقدار دقیق به حجم کار شما بستگی داره.

**کیفیت خروجی کم نمی‌شه؟** برعکس؛ skillها جای «بداهه‌پردازی هر جلسه» رو با رویه‌ی تأییدشده عوض می‌کنن.

**به هر ۴۵ skill نیاز دارم؟** نه. هر skill تا استفاده نشه فقط ~۵۰-۱۰۰ توکن جا می‌گیره؛ هر وقت خواستید پوشه‌اش رو پاک کنید.
